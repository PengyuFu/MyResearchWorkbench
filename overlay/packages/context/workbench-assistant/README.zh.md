# Workbench 对话与选中文字协助

[English](README.md) | 中文

此组件连接 MyResearchWorkbench 写作板、开发板与现有 DeepSeek Harness 对话，并通过已支持的编辑器接口执行操作。

## 对外说明的能力

- 在写作板或开发板中打开工作区已有文件。
- 从当前会话读取指定的选区或文档上下文。
- 生成可供用户审核、采纳或拒绝的编辑建议。
- 通过必要的文件与修订检查执行支持的 Word 原生命令。
- 在切换工作板时保持对话与编辑器关联。

完整软件可能包含另行许可的自然语言执行增强模块。其源码不属于公开集成代码的发行范围，实际可用能力以对应发行版本为准。

## 构建与许可

开发者应按照相应 MyResearchWorkbench 源码发行版附带的固定版本说明安装依赖。需要专有模块时，通过允许的发行渠道获取预构建运行组件；不需要获取内部开发资料，也不应让 AI 自行推断或重建缺失的专有源码。

本包的许可证说明见 [LICENSE-MIXED.md](LICENSE-MIXED.md)。上游及其他第三方组件保留各自的许可和署名。公开源码的授权不等于专有运行模块的独立再分发授权。

## 限制

本地安装的运行代码可能被接收者分析。JavaScript 打包和 Electron 归档均不提供绝对防逆向保护。完整功能、许可范围和测试结果以实际发布的版本为准。
