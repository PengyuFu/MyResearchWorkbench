# Workbench Word

[English](README.md) | 中文

Windows Host 服务为连续写作板保留二进制 DOCX 草稿，通过经过身份验证、限定工作区的 `workbenchWord` Remote 命名空间提供接口，不新增模型工具。

## Ownership and editing

浏览器为每个文档持有一个持续存在的 OOXML 编辑器。输入、接受 AI 替换、格式调整、撤销和重做共用这一编辑器。切换文件标签只改变视图，不替换文档模型和历史。Host 接收编辑器序列化的 DOCX 字节与只读文本上下文，不从 HTML 重建文档，也不调用 Word 或 WPS。

内置核心采用 Apache-2.0 许可；源码提交、本地排版补丁和包摘要记录在 `third_party/docx-editor/manifest.json`。字形处理代码随应用提供，所需字体从 Windows 已安装字体目录读取。缺失字体可能影响版式，编辑器会报告相关错误。

对话格式操作针对已确认版本排队，浏览器通过同一编辑器应用或拒绝，再结束队列记录。排队响应不表示已经修改。段落样式设置通过一次受编辑器约束的包事务，仅修改原有样式部件。

## Saving and recovery

Desktop 提供内置 Python、私有文件系统依赖和当前配置目录的绝对位置。工作进程验证字节、拒绝过期检查点并去除重复请求。编辑保留私有草稿，并在约一秒空闲后自动保存原文件；Ctrl+S 通过同一串行写入流程立即保存。恢复时先核对原文件，已改变或无法读取则保留草稿、显示原因并暂停自动保存；原文件匹配才继续自动保存。写入受阻时可明确重试，或另存到新的路径。

保存期间排除竞争写入，核对原文件身份及内容，先落盘备份再发布。持久日志可在原文件缺失时恢复，不能覆盖后来出现的外部文件。另存为拒绝覆盖已有目标。

会话记录包含已确认检查点引用、打开的标签、视图位置和未确认的二进制输入。恢复验证指定检查点的摘要；未确认输入须明确重试，不能静默重放。清理策略保护完整会话引用、新近未确认检查点及未解决保存日志，不扫描或删除其他版本配置目录。

## Model Experience

选区助手接收有界、已确认的文本，文本建议在用户接受前不写入文档。接受时检查原版本与选区原文，再进入手工输入共用的编辑器和撤销历史。该服务不调用模型。

## Known Limitations and Deferred Work

目前 Host 仅支持 Windows。含宏、加密、外链或有效编辑保护的文件被拒绝。尚不支持的 OOXML 结构保留包内内容，但不保证可直接编辑或准确显示。版式结论限定于已记录的报告及对照文件，不能推广为覆盖全部 Word 功能。当前进程内切换标签保留撤销历史；持久检查点恢复内容与视图，不承诺恢复上一个进程的撤销栈。旧的原生 Word 校样生成与段落输入覆盖层已退出运行路径。
