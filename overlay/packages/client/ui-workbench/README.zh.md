# 写作与开发工作视图

[English](README.md) | 中文

## 摘要

Workbench 在既有对话旁放置写作和开发面板，保留 Session、模型、Agent 预设及权限。每个物理文件只有一个所属板块和一个缓冲区，切换板块保留标签页、选区、滚动及撤销。工作区相对路径拒绝过期工作区响应。

## 布局与对话

分隔线调整两个保持挂载的界面宽度，方向键微调，双击恢复默认。宽度低于 880 CSS 像素时，焦点控件仍保留两侧界面。两种板块均支持跟随指针左右移动并阻尼落位，Escape、指针取消和失焦取消拖动。减少动态效果会关闭动画。沉浸模式保留对话输入框、模型、权限、统计、紧凑文件切换、文件和更多菜单，文档页边距不变。毛玻璃仅用于圆角外壳，正文和比较区域不透明；高对比度及减少透明度使用不透明外壳。

协助将当前文件、对象或选区附加到主输入框，不另设输入。回车清空已发送草稿并保留后续输入。快捷指令呈现为持久化的用户与结果对话。澄清选项是可点击的完整清单，也可在同一输入框补充文字。忙碌拒绝、取消、部分执行和保存失败均可见。转交 Agent 时保留快捷节点标识并将其隐藏，让普通 Agent 对话继续；撤回已经实例化的节点会中断事件流。

## 科学写作

支持的 LaTeX 范围投影到 Tiptap/ProseMirror，MathLive 提供可编辑公式。前置信息、章节、插图、引用和表格单元格保留源码标识。有界修改保留无关宏、注释、包裹结构及换行。不支持的语法保持原样并标明。源码缓冲区为权威，成功生成的本地 MiKTeX PDF 和 SyncTeX 快照负责最终排版，导航拒绝过期构建输入的位置。

插图或表格从对话开始，要求明确位置及核验过的附件或项目资源。IndexedDB 暂存最多八个文件、每个 16 MiB、合计 32 MiB，不自动过期。采纳后通过源码事务保存资源，撤销删除插入内容但保留已提交资源，残留和未完成写入可检查。支持 PNG、JPEG、PDF 导入，既有 EPS 使用可用的预览文件。引用发现最多读取 64 个项目源码/文献文件、4 MiB 内容，保留键名并报告缺失或重复引用。跨文件重命名要求独立明确操作。

<a id="word-editing"></a>

## Word 编辑

本地 Apache-2.0 OOXML 核心负责字节、布局、原生选区和撤销；Host 校验二进制检查点及原文件写入。既有 DOCX 部件保持原样，不从 HTML 重建。打包的 HarfBuzz 初始化前解析本地字体字节，不打包系统字体。初始化失败可见，此时布局测量无效。视口在 50% 至 100% 缩放原始页面，不改变页边距或换行。

输入、格式和采纳建议使用同一原生编辑器。单段替换先在原有 run 内插入再删除旧文字，保留原生字体、字号及相关 run 属性。多段替换通过原生命令恢复捕获的基础字体和字号，不推断任意混合样式重新分配。表格自动适配支持按内容、窗口及可选行高重置。段落分页和页眉页脚使用普通原生操作，校验既有文字及版本。复杂区域和不支持的结构组合明确失败。

共用操作路径发布当前上下文、验证目标/版本、领取实时一次性 Agent 请求、应用、保存并回报。历史通知和重复领取不能重复修改，Host 核验保存结果。操作成功后，把未被用户替换的协助引用更新到本次提交版本，下一条指令无需重新选取；无关修改和新引用仍执行各自的版本校验。参见[路由与学习服务](../../context/workbench-assistant/README.zh.md#conditional-learning-and-recovery)。

## 审阅、保存与恢复

建议在采纳前不进入正文。采纳、放弃、细节和继续调整显示在目标文档下方，细节比较不重挂载编辑器。科学修改显示数值、单位、引用和源码差异。采纳校验捕获的文字/版本并生成可撤销事务，保存状态单独报告。未采纳建议不能写文件或开始编译。

保存按文件串行并比较上次磁盘版本。干净缓冲区刷新外部变化，脏缓冲区冲突保留草稿并显示处理入口。Word 空闲约一秒自动保存，Ctrl+S 立即保存，保存期间的新输入会触发下一次写入。原稿未变则不重写。关闭脏 Word 文件先尝试保存，失败保留保存、放弃、取消选项。放弃只影响未保存修改，另存副本必须使用工作区内的新本地路径。

应用拥有的单个 IndexedDB 写入器按原始 Session 和 Host 确认的工作区，在 150 ms 内原子提交场景及草稿，连续输入不延迟提交。正常退出捕获已挂载编辑器并等待严格持久化完成后关闭 Host。崩溃恢复最近成功提交，最后未提交输入无法保证恢复。标签页、两个板块、视图、选区、PDF 位置和待审阅标识不按数量或时间淘汰。恢复不采纳建议、不重跑模型或任务。Word 仅在原文件身份和内容一致时恢复自动保存，冲突需解决；文件缺失或不可访问时保留草稿。场景格式 2 保存检查点和预览标识，无效场景暂停清理，格式 1 不授权回收。

<a id="development"></a>

## 开发

CodeMirror 提供 Python、MATLAB、C++、CUDA 高亮、板块配色及文件标识。创建与执行仍是对话操作。运行输出和图片属于实际任务，交互输入使用更多菜单中的既有 PTY 终端。重连只能重新附加到同一 Host 仍拥有的进程。两板块共用 Ctrl+S，写作另保留编译及 Ctrl+Alt+B。

<a id="validation"></a>

## 验证

控制器测试覆盖保存冲突、领取、回执、撤销、选区、重连和任务。真实对话组装器回归覆盖快捷增量转交 Agent 后消息流不中断。科学编辑和资源测试覆盖源码标识、存储、配额及哈希。打包 EXE 使用自有合成文档及配置档，检查原生自动适配、Agent 执行、学习复用、字体字号保留、撤销及重启。私有文稿和运行证据留在源码树外。

## 模型体验

### 显式操作与上下文

#### 模型看到什么

支持的直接操作使用本地/学习路由、有界解析及既有 Session Agent 回退。客户端保留选区并验证每次执行回执。菜单提供工作区学习数量、暂停/恢复、清空，不改变模型或权限。手动编辑、保存、切换、编译自身不调用模型。明确协助会记录选中文字、有界上下文和指令；审阅决定不再次请求模型。 已确认上下文通过 `workbench_read_context` 进入模型。

#### Token 影响

本地或已学习的命中不需要模型 token；未命中时仅发送有界目标、指令与所需工具结果，模型接管会追加既有会话消息。

#### KV 缓存影响

稳定工具定义可以保留公共前缀；变化的选区、参数和结果会改变后续输入。不保证提供方的缓存命中率。

<a id="known-limitations-and-deferred-work"></a>

## 已知限制与后续工作

- 可视化 LaTeX 编辑不实现任意 TeX 展开或期刊分页。开发板不是调试器、语言服务器或工具链安装器，运行取决于已安装工具。浏览器存储可能失败或被淘汰。资源写入使用经核验的恢复日志，不是文件系统整体原子事务。字体不可用、不支持的 OOXML 及不同机器需要独立验证。旧的未确认文字投影草稿需用早期应用恢复。自动浏览器检查不覆盖手动输入法候选窗口或长时间编辑。
